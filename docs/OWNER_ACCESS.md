# 手机权限、审批记录与回合失联

ADR-012 阶段 B，接续 [审批类别与风险](TYPED_APPROVALS.md)。两端使用同一只读投影，保留 MainAgent 与原确认门，不增加权限授予入口、审批库或任务调度器。

## 查看入口与权限

- Desktop：助理面板「审核记录 → 手机权限与审批记录」，显式点击核对后读取。
- iPhone：「我 → 手机权限与审批记录」，要求原生会话有效且设备钥匙已被信任、手机写入已开启。
- 内容针对手机 `owner_device` 档案，不是整个 Desktop 工作区的完整权限清单；这里只查看，不能设置任务范围或永久授权。

服务端读取原 trust 档位，再由内核 `resolve` / `ceiling` / `pre_authorized` 求实际级别；即使保存了 FULL，手机档案仍夹到 READS。工具白名单和污点规则不变。普通操作可免逐次确认不代表所有工具可用；具体工具仍受能力档案与各自围栏约束。

## 历史来源与隐私

复用原审批审计、Codex `actions.json` 与任务单 `ledger.json`。审批审计最多读尾部 2 MiB / 500 条；两个领域源各限 2 MiB，最多取 100 条 Codex 动作、200 张当前任务单。按已记录时间汇总最近 100 条决定，时点缺失的旧项不补造日期。投影不转发正文、工具参数、结果、会话标识、项目名或文件路径，身份按来源命名空间散列。

卡片处理、内核决定和领域决定是不同记录。领域审批事件保存在原动作或任务单中，与原状态转移同锁、同次落盘；最多保留 20 条，超过后明确标记不完整。后台审核、系统撤回、人工决定及 App / IM / 运行端入口分别记录。原始调用没有声明来源时保持 unknown。

审批事件的时间、结果和来源不随发送回执或任务进度更新而覆盖。列表另显示“当前来源状态”：Codex 受理不代表完成，任务单 done 不代表验收。旧记录只有 sent / done 等状态时不反推用户批准、来源和审批时点；缺失或损坏的元数据明确待核对。

聚合只读取原文件，不调用过期处理、补收、下发、自动重试或核心控制。当前领域表之外的归档与撤销等其它来源尚未汇总，这不是全部审批档案。

`audit_snapshot` 区分 `current`、`partial`、`unavailable`；读不到文件、尾部截断或损坏内容不会在新页面冒充完整的空历史。首次尚无审计文件可返回当前空记录。旧 `list_audit` 接口继续兼容。新 history.sources 分别报告 audit / codex / dispatches 的状态，一个来源失败不隐藏其它可读记录。

## 接口与边界

| 路径 | 身份与范围 |
| --- | --- |
| `GET /api/assistant/access` | 原管理员鉴权，仅 General |
| `POST /api/assistant/app-relay/access` | 专用转发令牌 + 回环来源 + General；管理员令牌不能替代专用令牌 |
| `GET /api/mobile/native/access` | 原生会话 + 已信任设备；等待后复核本机会话、设备和开关 |

手机端没有管理员接口或额外写操作。配置转发时从常驻助理读，手机网关不另建数据源；只把新增原生 GET 精确列入 Caddy 模板与 General 路由合同。两条内部 access 路径加入发布检查的公网关闭核对。未自动修改线上入口。

## 重启或清理后的旧回合

App 还持有原回合 id、但常驻助理已找不到时，状态查询返回兼容旧客户端的终止状态 `failed`，另带 `outcome=unknown`、空卡片和明确核对提示。这里失败的是进度核对，不能据此认定之前的动作没执行。

手机停止轮询并移除旧卡片，先读主聊天；不自动重新发送消息、重放批准或恢复执行。正在等待的新响应按连接代次和回合 id 复核；换登录时清除旧对话投影。此轮不持久化内存卡片，也不恢复 App 自身被终止前丢失的回合标识。

## 剩余范围

任务/定时任务/连接器范围授权、完整权限管理、历史归档读取与其它领域审批记录留在后续阶段。源码测试与模拟器构建不代表真实 Face ID、真机安装或线上部署已验收。
