# Desktop 日常使用与交付基线

2026-10-09，PRD 第55节。本阶段是本地日常使用收敛候选，未正式发布为稳定版。
逐轮证据在[验收记录](DESKTOP_ACCEPTANCE.md)，本页统一范围与操作入口，不抹掉历史失败。

当前Desktop版本为 **0.1.10**（第65节）。顶栏显示版本/源码短摘要，设置→常规显示完整构建标识与时间。
每次构建自动生成时间+源码摘要标识，不必提交Git即可区分工作区改动；相同源码再次构建有新标识。
展示的是窗口加载时固化的版本，不跟随磁盘上后来安装的包变化；⌘Q重开后才加载新版本。
正式版本号按交付阶段递增，构建标识每次自动变化，协议版本与provider模型版本仍分别管理。

## 用户入口

打开`/Applications/VortoCode.app`。仓库构建包、QA包与临时备份用于开发或回退。
Vorto Write是独立写作工具，VortoCode更新不替换它。

安装新包后用 **⌘Q** 退出旧实例再打开；红色关闭按钮隐藏窗口，不能靠它加载新代码。
模型设置核对地址、模型及连接，Key继续使用既有配置，本页不复制凭据。
联网结果需核对来源，偏题搜索不能当作已经完成核实。
MCP在插件页手动连接/重试；Skill按项目加载，General不加载仓库Skill。

## 固定交付命令

在`desktop/`内执行：

```bash
npm test
npm run test:delivery
VORTOCODE_NOTARY_PROFILE='' npm run bundle:dev-signed
npm run install:built-signed
npm run verify:installed
VORTOCODE_RUNTIME_BIN=/Applications/VortoCode.app/Contents/Resources/runtime/vortocode-runtime npm run sidecar:smoke
```

`install:built-signed`只安装已构建签名且与证据匹配的包，不重复构建。
原`install:dev-signed`构建后复用同一替换函数，不依赖会话临时脚本。
替换前核验身份，保存/核验旧包备份，再核验同卷暂存新包，整包换入后重新核验。
发布/核验失败回退原包；回退失败保留暂存/备份路径并报错，不删恢复资料。
安装后的sidecar健康独立检查，失败保留备份并报错，不声称已经回退或通过。
这些命令不启动/关闭GUI、不提交或合并、不上传公证/正式发布。
构建证据位于`desktop/src-tauri/target/release/dev-signing-evidence.json`，安装日志给出备份路径。

## 收敛验收

源码/测试、浏览器、签名构建、隔离runtime、真实本机模型、原生GUI、正式发布分别报告。
已有本机模型有界探测只保留其实际范围，不将一次查询推广为全部功能的稳定保证。
原生GUI、输入法、Spaces、VoiceOver、Hook及正式发布仍未验收，历史失败不改记通过。
后续优先搜索相关性与会话恢复的实际复现，不用堆新功能替代验证。

## 会话操作与信息（0.1.2）

输入框「添加」展开带说明的菜单；输入`/`可查找附件、项目、运行信息、模型设置和新会话，
项目内另有源码引用。上下键/Enter选择，Esc关闭，Shift+Enter换行。标题栏「运行信息」或
输入框「上下文」打开右侧信息页；该页不自动抢占你正在看的代码/预览。
上下文是最近快照估算，不是实时计费；压缩按历史预算在下一模型回合前尝试，不能看窗口
占比猜压缩时间。旧runtime未提供压缩开关时显示未知。effort和手动压缩当前未接通。

## 关闭与退出（0.1.3）

macOS红色关闭按钮隐藏主窗口，保持应用与会话运行，不再把窗口最小化到Dock右侧。
应用正常运行时保留Dock应用入口，点击图标或再次打开应用恢复主窗口。⌘Q/菜单退出仍
停止原runtime。关闭后迟到的页面加载/启动兜底不能自动恢复窗口。此行为源码/构建可核验，
原生Dock、隐藏/恢复点击与后台任务实际持续运行仍未验收；历史失败记录不变。

## 上下文百分比（0.1.4）

输入框只显示百分比；点击打开简短浮层，不再切换到运行信息栏。浮层可按Esc、点击外部
或关闭按钮收起。模型窗口未知时百分比来自历史预算，浮层/无障碍标签会说明；无快照
显示「—」，不伪装为0%。右侧信息页的大段上下文说明已收起，仍可点击其百分比看浮层。

## 日常页面（0.1.5）

运行信息先看状态与非空的步骤/活动，会话详情按需展开；等待确认仍在输入框上方处理，
连接中断从连接设置恢复。首页连接模型不用先登录，账号页也可直接跳到本地模型设置。
版本与构建信息在设置常规中展开，顶栏仍显示版本。内容准则见[页面内容规范](DESKTOP_CONTENT_GUIDELINES.md)。

## 本机文件授权（0.1.6）

对话中给出普通文本的完整绝对路径即可请求读取，无需先选项目或配置新环境开关。
设置→授权级别可选每次确认或只读免确认；General上限仍只读。一次允许不保存目录授权，
文件变化需重新批准，敏感文件/目录扫描/跨目录写入执行未开放。详见[文件访问合同](DESKTOP_FILE_ACCESS.md)。

## 确认卡授权与监管（0.1.7）

确认卡中可保存只读免确认，本次仍需单独允许。新版Desktop只提供每次确认/只读免确认，
历史完全信任保留记录但实际降到只读；写入、执行与外发审批不能用升档跳过。shell含只读
也确认，已识别敏感文件/危险命令和原路径、deny、沙箱闸保持；不保证识别全部脚本或第三方风险。

## 新对话草稿（0.1.8）

已在空白页时再次点新对话会复用当前草稿，不增加最近记录；有实际消息/活动/计划/队列
或显式名称时才成为内容记录，运行/审批/后台任务仍保持可见。旧纯空记录隐藏，文件不批量删除。

## 当前执行与确认恢复（0.1.9）

工作台主入口为当前执行/看板/更多。执行时可看模型计划步骤、当前工具和本会话下派任务；
开发任务进入任务卡展开原依赖图。没有计划会明确提示未提供，不制造进度。
确认发送后等待运行端回执；失败仍保留卡，通过“核对状态”读取运行端是否仍等待，再人工选择。
核对不等于批准或执行成功。待处理列表回到原会话确认卡，无第二个批准入口。

## 任务中心与会话分离（0.1.10，取代0.1.9导航）

左侧任务中心在主区域提供看板/任务/目标/待处理；会话右侧仅展示当前执行进展，
不再放下派列表、全局管理入口或全局计数。原辅助工具保留在更多中。后台管理变化不抢主区域焦点。
