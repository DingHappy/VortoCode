# 助理插件

私人助理（General 的 Desktop / IM 会话）通过插件接入日历、邮件这类外部数据。
现有插件：日历、Notion、邮件，都是只读。代码在 `src/plugins/`，每个插件是一个名字、一份凭据、一组工具，外加一段可选的早报内容。

## 规则

- **凭据在哪，插件就在哪启用**：凭据只认 `~/.vortocode/connectors/<名字>.token`，要求本人所有、权限 600，
  与 GitHub 连接器共用同一套读取规则和本机撤销规则。删掉这个文件或在本机撤销，插件就停用。
- 会话装配时，按此刻已启用的插件挂上工具，所以同一会话里的系统提示不变；新放进去的凭据从下一个会话起生效。
  每次调用工具都会重新读凭据，所以撤销立刻生效。
- 插件带回来的都是外部内容。工具一律标记为不可信来源，读进来当回合即带污点，之后的对外动作要回到人工确认。
  早报里的插件内容只附在模型写完的正文后面，不进模型上下文。
- 现有插件都只读。以后要做写入动作（发邮件、建日程），必须先出草稿，再经过确认门。

## 在 Desktop 里查看

助理的「身份」页有个「插件」区块，会列出每个插件的状态：已接上、未接入、凭据文件不可用，或已在本机撤销。
- **检查**：真去读一次，例如「能读到，共 N 条日程」。读不到时写明原因，但不带凭据。
- **移除凭据**：删掉助理所在电脑上的凭据文件，插件立即停用。

- **填写 / 更换**：贴上订阅链接或令牌，点「保存并检查」。服务端先校验格式（日历要 https:// 或 webcal:// 开头，
  Notion 要 ntn_ 或 secret_ 开头），再原子写成本人只读的凭据文件（目录 700、文件 600），然后真去读一次。
  凭据只写进文件：接口返回、日志和模型上下文里都不出现；格式不对时，报错里也不回显你填的内容。
  它和 Desktop 的 API 令牌走同一条连接。常驻电脑在局域网时，这条连接是 http；不放心的话，仍可以按上面的方式在那台电脑上手工放文件。

## 日历（只读）

- 凭据：日历的**只读订阅链接**（ICS）。iCloud、Google、Outlook、飞书都能导出；`webcal://` 链接会按 https 读取。
- 工具 `calendar_events(date, days)`：查某天起 1–14 天的日程，结果里只有时间、标题和地点。
- 早报会附一段「📅 今天的安排」；读取失败时会写明原因，但不显示链接。
- **开始前提醒**：常驻助理每分钟巡检一次，日程开始前 15 分钟往手机推一条
  「⏰ 14 分钟后（10:00）：评审会 @3 楼」。同一个日程只推一次，没推出去的下一轮再试；全天日程和已经开始的日程不提醒。
  这些时间是你自己排的，所以安静时段也照常推送。
  提前多少分钟用 `VORTOCODE_CALENDAR_REMIND_MINUTES` 调整（0 表示关闭，最多 120）。日历缓存十分钟，刚加的日程最多晚十分钟被看到。
- 支持常见的重复规则：每天、每周几、每月同日、每年，可带间隔、次数、截止日期、例外和单次改期。
  更复杂的规则只算第一次，并在结果里注明可能漏算。
- 订阅链接就是密钥，拿到的人能看到全部日程，所以它不进配置、系统提示、日志或工具结果。
  报错信息里也只写原因，不写链接。

放置方式（在跑助理的机器上执行，然后粘贴链接、回车、按 Ctrl-D，链接不会进 shell 历史）：

```bash
mkdir -p ~/.vortocode/connectors && chmod 700 ~/.vortocode/connectors
(umask 077; cat > ~/.vortocode/connectors/calendar.token)
```

## Notion（只读）

- 凭据：Notion **内部集成**的令牌。在 notion.so/profile/integrations 新建集成，能力只勾「读取内容」。
- 集成只看得到你在页面右上角「连接」里加给它的页面（含子页面），能看哪些由你在 Notion 里决定。
- 工具 `notion_search(query, limit)`：按关键词找页面和数据库；不填关键词时列出最近编辑的。
  工具 `notion_read(page_id)`：读页面的属性、正文和一层子块；如果给的是数据库，就列出最近 50 行。
  `page_id` 也可以直接贴页面链接。
- 带令牌的请求不跟随重定向；报错时说明原因，但不带令牌。

放置方式同上，文件名为 `notion.token`。

## 邮件（只读）

- 凭据：`邮箱:授权码`，QQ、163、126、iCloud、Gmail 等常见邮箱会自动识别服务器；其他邮箱写成
  `imaps://邮箱:授权码@服务器[:端口]`。授权码是在邮箱设置里开启 IMAP 后生成的客户端专用密码，不是登录密码。
- 只读：收件箱用只读方式打开，取邮件内容时也不会标成已读，不移动、不删除，也不能发信。
- 工具 `mail_list(query, days, unread_only, limit)`：列出最近几天的邮件（最多看最近 300 封），可按主题或发件人关键词筛选。
  工具 `mail_read(uid)`：读一封邮件的正文；附件只列名字，超过 2MB 的邮件不读。
- 早报会附「📬 最近一天未读 N 封」以及最新三封；没有未读时这一段不出现。
- 邮件可能是钓鱼。内容一律按外部资料处理，带标记的回合里，往外发东西要你确认。
- 服务器必须在公网上，只用加密连接（993 端口）。IMAP 不走网页代理，所以常驻电脑连不上 Gmail 这类境外邮箱；QQ、163、iCloud 可以直接连。

## 加一个插件

在 `src/plugins/` 写一个模块，提供 `build_tools()`，需要的话再提供 `morning_brief(now)`，
然后在 `available_plugins()` 里登记名字、标题和一句用法提示。
工具通过 `load_connector_secret(名字)` 在调用时读凭据，报错信息里不能带凭据原文。
