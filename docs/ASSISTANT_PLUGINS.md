# 助理插件

私人助理（General 的 Desktop / IM 会话）通过插件接入日历、邮件这类外部数据。
代码在 `src/plugins/`，每个插件是一个名字、一份凭据、一组工具，外加一段可选的早报内容。

## 规则

- **凭据在哪，插件就在哪启用**：凭据只认 `~/.vortocode/connectors/<名字>.token`，要求本人所有、权限 600，
  与 GitHub 连接器共用同一套读取规则和本机撤销规则。删掉这个文件或在本机撤销，插件就停用。
- 会话装配时，按此刻已启用的插件挂上工具，所以同一会话里的系统提示不变；新放进去的凭据从下一个会话起生效。
  每次调用工具都会重新读凭据，所以撤销立刻生效。
- 插件带回来的都是外部内容。工具一律标记为不可信来源，读进来当回合即带污点，之后的对外动作要回到人工确认。
  早报里的插件内容只附在模型写完的正文后面，不进模型上下文。
- 现有插件都只读。以后要做写入动作（发邮件、建日程），必须先出草稿，再经过确认门。

## 日历（只读）

- 凭据：日历的**只读订阅链接**（ICS）。iCloud、Google、Outlook、飞书都能导出；`webcal://` 链接会按 https 读取。
- 工具 `calendar_events(date, days)`：查某天起 1–14 天的日程，结果里只有时间、标题和地点。
- 早报会附一段「📅 今天的安排」；读取失败时会写明原因，但不显示链接。
- 支持常见的重复规则：每天、每周几、每月同日、每年，可带间隔、次数、截止日期、例外和单次改期。
  更复杂的规则只算第一次，并在结果里注明可能漏算。
- 订阅链接就是密钥，拿到的人能看到全部日程，所以它不进配置、系统提示、日志或工具结果。
  报错信息里也只写原因，不写链接。

放置方式（在跑助理的机器上执行，然后粘贴链接、回车、按 Ctrl-D，链接不会进 shell 历史）：

```bash
mkdir -p ~/.vortocode/connectors && chmod 700 ~/.vortocode/connectors
(umask 077; cat > ~/.vortocode/connectors/calendar.token)
```

## 加一个插件

在 `src/plugins/` 写一个模块，提供 `build_tools()`，需要的话再提供 `morning_brief(now)`，
然后在 `available_plugins()` 里登记名字、标题和一句用法提示。
工具通过 `load_connector_secret(名字)` 在调用时读凭据，报错信息里不能带凭据原文。
