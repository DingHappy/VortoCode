# 记忆只读导出

Desktop「身份 → 记忆」提供预览和 Markdown 下载，由同一只读快照 API 返回内容。接口读取当前实例原有记忆资料，标注来源、时间、版本与覆盖范围；它不是另一套记忆库，不写回、迁移或自动修复原库。

SQLite 连接采用只读方式，固定读取范围；缺失、损坏、符号链接、敏感内容和超限资料按实现合同处理。响应禁止缓存，导出不提供新的任意文件入口。前端在连接或范围变化后丢弃迟到结果，预览与下载使用同一快照。

原 SOUL/关于你编辑器保持原行为；本 PR 不修改主提示、成员返工、工具声明、权限或调度。新 API 有 Desktop 消费者，并同步路由基线。

自动检查使用临时库与合成快照，覆盖鉴权、范围、脱敏、损坏记录和前端下载/过期响应。不读取真实用户记忆，不证明原生安装体验或真实模型召回质量。
