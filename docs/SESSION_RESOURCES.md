# 当前会话资源总览

2026-11-01。基于待审网站接管分支，新增对话输入区的折叠“当前会话资源”。这是源码实现，
未安装或部署。复用原工具命名空间、浏览器/Android 会话、业务插件和 MCP 观察，不建立
资源数据库、另一套插件注册表、执行器或凭据保险箱。

## 使用与语义

展开后只读取当前连接、当前会话已装配资源的状态；可以手动刷新、定位当前网站确认卡，
或跳转原连接管理/浏览器设置。不会启动浏览器、发现或附加设备、连接 MCP、加载模型、
读取凭据、发出业务请求或代答确认。不自动打开总览，不后台轮询，也不在超时后自动重试。

“已装配”“已有连接观察”“等待人工处理”“上次操作待核对”“本会话未提供”分别展示。
这些状态都不是动作授权、站点登录证明或业务验收。“未提供”仅指当前工具装配，不表示
宿主没有安装依赖或没有配置账号。业务连接器只显示原工具已装配，账号状态保持未核实。
浏览器账号标签需要真人核对实际登录账号；没有凭据时不自动导入日常浏览器登录态。

显示本机或已登记远端运行端的别名；它是当前连接的目标说明，不是独立硬件认证。
Android 区分控制端与设备标签。MCP 不假定在 Desktop 所在电脑执行，实际位置按服务配置
另行核对；业务服务显示由当前运行端发起访问。没有实现跨宿主自动发现或凭据同步。

时间分为本次读取时间和原 MCP 连接观察时间。浏览器观察只读当前会话内存；动作前仍检查
原持久授权与页面边界。Android 观察只读已附加会话和本地待核对标记，不调用 Appium。
不通过刷新总览检查网站、设备或账号是否在线。

断连、请求失败、任务出现新进展，或读取后经过一分钟，保留的结果标为待核对。过期只是
本地展示失效，不触发请求。切会话、换客户端或重连代次变化时隐藏旧记录；不能用上一台
电脑的状态解释当前任务。用户展开或手动刷新时读取；沿用原有回合结束时的资源刷新，
不增加轮询或自动重试。旧运行端无此能力时五秒后结束等待。

## 当前对话的能力入口（2026-11-05）

输入框「+」菜单的「此对话的能力」或 `/capabilities` 打开只读窗口。它复用同一会话读取器，
显示当前运行端别名、已装配工具的分组清单和上述连接观察，不增加常驻顶栏。工具的「声明只读」
「可能改动状态」「读写属性未确认」只解释原 Tool 声明；所需能力仍在执行时由 ToolRuntime
检查，清单不是有效授权证明，也不证明第三方工具实现无副作用。

未初始化的会话不会为查看清单而初始化。旧服务端、损坏或未知版本的工具清单显示「尚未确认」，
不显示为零工具；兼容的连接观察仍可保留。清单不完整时显示 `N+`，未列出的工具保持未知。
断线或过期的记录明确标为上次记录，断线时刷新禁用。切换会话/运行端关闭窗口，并由原读取器
隔离旧回包。Escape 关闭后回到输入框；正文滚动时标题、关闭与底部导航仍可达。

「管理当前连接」只跳转原连接管理；「这台 Mac 的权限设置」明确只影响本机。没有新增启用、
登录、安装或授权按钮。原内联「需要核对」信息被用户展开后，刷新恢复正常也不突然消失；
用户收起后才恢复安静隐藏。

`status.resources.tool_inventory` 是可选、版本为 1 的元数据投影，最多 256 项：只返回安全格式
的工具名、严格布尔或 null 的 `read_only`、最多 16 个能力声明名或 null。非法项省略并标清单
不完整；不导出描述、参数/schema、处理函数、凭据或账号探测结果。不新增 API、WS 消息类型、
存储或模型工具字段；旧客户端忽略新字段。

## 工程合同

- `ToolResource` 是原 Tool 的可选可信观察描述，一组工具共享一个描述；不会导出到模型工具
  schema。观察回调只读取自己的有界元数据，不能调用工具处理函数、凭据加载或网络接口。
  这不是第三方代码沙箱；新增适配器仍须经宿主审阅。
- `gateway/session_resources.py` 从已有工具命名空间读取描述，每个身份只观察一次。重复身份
  保守标为未知；观察失败只给固定错误，不暴露异常正文。最多检查 2048 个工具、返回 32 项
  资源，超限显示未完整读取，不把未列出的能力当成不存在。
- 通过原 WS `get_status(resources=<nonce>)` 请求，原 `status` 追加可选资源观察。仅查询 WS
  自己绑定的已加载会话，并核对工作区；不创建会话、不读取其他会话、不新增 HTTP API。
  结果不落盘、不进事件 journal，也不作为授权依据。旧端忽略新增字段，旧运行端正常返回
  无资源字段时，新端显示未核实，不自动探测其他接口。
- Desktop 按 nonce、准确客户端对象、会话和原 Gateway 连接代次核对回包。重连复用原
  snapshotEpoch，不增加第二份连接身份。旧回包、旧会话或损坏结构不能替换当前观察。
  发送失败/五秒超时不会自动重发；资源更新期间的新进展使回包仍保持待核对。
- “查看当前确认”仅在观察引用与当前确认 ID 相同时显示，只定位原卡片，不执行或批准。
  管理按钮只导航到原定制/插件页和浏览器设置；没有新增启用、安装或授权开关。

## 验证与未验证范围

`test_session_resources.py` 覆盖同源去重、失败脱敏、歧义、清单边界、MCP 原时间/范围、
零浏览器检测/启动、零设备加载/请求、零凭据读取，以及 WS 会话/工作区隔离。
实际接管等待时能读取元数据，不能借观察读取页面；Android 超时的待核对标记也不触发设备请求。

前端覆盖协议结构、nonce/客户端/会话/连接代次、请求超时、断连、失败、过期与新进展。
组件夹具 `desktop/qa/session-resources.html` 只使用合成传输，复用生产读取控制器和组件；
可验证切运行端后的旧回包、断连和 390px 换行。夹具单独移除整机最小宽度，不改变应用宽度合同。

完整已安装 Desktop、真实浏览器、真实设备、账号授权和业务调用不由这些检查证明。
当前范围是浏览器、Android、已装配业务插件和原 MCP 会话；其他资源保持未知，不声称发现所有设备。
