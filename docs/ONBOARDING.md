# 首次使用：安装与连接（P2）

2026-11-13，按主人确认的个人模式路线实施。首次选择「在这台 Mac 运行」或「连接已有助手」，
每个运行端仍保留自己的资料、模型和会话。先核对旧登记、旧聊天、本机进程和模型配置；
没有新引导记录的已有用户保留原启动路径，不强制重做设置或搬资料。

## 两条路径

本机路径复用 [本机常驻合同](LOCAL_RESIDENT.md)：检测已有服务；新安装先用原模型配置服务
保存模型，再明确同意复制，分别点击安装、启动、连接。安装时不开放定时选项，固定关闭
cron；IM、heartbeat 和主机操作仍沿用原禁用设置。已有服务保留原配置，不自动重装、更新
或启动。安装、停止及身份核对继续交给原生控制器，网页不传入程序或任意环境变量。

模型表单共用 `useLlmProfile` 的保存、版本冲突与启动回执；获取列表共用
`LlmConnectionCheck`。保存配置、查询模型列表不等于真实推理或工具验证。首次本机安装需要
一份可复制的已保存配置，因此先准备模型，再安装服务。常驻配置是独立快照，不实时同步。

远端路径共用原原生地址校验、注册确认、Keychain 与连接代理。引导传入 `deferSelection`，
新登记带 `assistantPending`，追加到现有登记而不替换默认；容量满时失败并保留旧记录。
原有入口省略此参数时行为不变。连接成功后，由同一次切换调用显式 prepared 选择，核对原
远端 ID 与地址后清除待选状态。本机受管登记仍必须走原运行实例核对，不能用此标记绕过。
已登记目标重试复用 Keychain，不把令牌再放回输入框。修改地址或名称后重新核对登记。

## 进度、恢复与取消

`STORAGE_KEYS.runtimeSetup` 只保存版本、pending/complete、运行位置选择或完成后的登记 ID，
不保存地址、模型内容、复制同意或凭据。新用户选位置前不启动临时引擎。未完成记录优先于
途中保存的模型和新增登记，重新打开后仍回到未完成路径；服务状态重新读取，不信任旧步骤。

只有连接与原默认选择保存均成功后才记 complete。之后按精确登记 ID 恢复，失败留在该目标
的恢复页，提供重试或重新选择，不启动备用本机引擎。旧项目自动恢复、默认助手重试在引导
期间暂停，完成显式选择后不会把会话再带走。待选条目从不参与自动默认选择。

记录损坏、版本不支持、原目标丢失或旧配置无法读取时明确提示；读取失败先重试，不把未知
当空白安装。本机模型读取失败不阻止已明确的远端恢复，也不改变已有用户的原启动路径。
新注册失败不会设成默认，原生默认选择保存失败走原连接清理；连接已成功但
浏览器进度保存失败时分别说明结果，保留已核对的连接并等待重试。进行中的安装、启动与连接
保持单飞，完成前不能返回或切目标；关闭应用后重开会重新核对实际结果，不承诺中途强停。
已保存配置与安装程序保留，不因返回步骤而自动删除或恢复任务。

设置 › 电脑与连接可重新打开同一引导。已有用户在当次引导中可返回原助手；取消只还原此前
的引导记录，显式保存的模型与安装结果仍保留。旧会话、旧资料和旧自动化不迁移或合并。

## 验证范围

- `runtimeOnboarding.test.ts`：新旧启动分流、中断记录、精确恢复、异常记录、成功后完成、
  失败/迟到完成隔离。
- `RuntimeOnboarding.test.tsx`、`LocalResidentCard.test.tsx`：入口、来源说明、读取失败、
  模型保存阻断及复制同意/定时关闭。
- `residentConnection.test.ts` 与 Rust 远端登记测试：显式 prepared 选择、原默认保留、
  未确认不落盘、已知登记不重排、容量满不淘汰、本机选择边界。
- `desktop/qa/runtime-onboarding.html`：真实组件与 hook 的合成 IPC 页面，支持完整 App 新装
  分流、安装失败、远端失败、原目标恢复失败与不支持设备。不会安装或连接真实服务。

样式沿用原设计变量，原生对话框提供焦点隔离，步骤变化定位标题，窄窗口可滚动。
浏览器夹具证明的是界面与回执合同；签名版 App 的 LaunchAgent、原生确认、Keychain、
窗口退出/休眠、真实远端与模型效果仍需分别验收。本 PR 不发版、部署或修改主机配置。
