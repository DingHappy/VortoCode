# 角色素材来源与使用

- `role-family-reference.png`：主人在本次对话中选定的原图，原样保存。
- `general.png`：珊瑚橙总助手，无配饰。
- `research.png`：紫色研究助手，黑框眼镜。
- `development.png`：绿色开发助手，深色耳机。
- `calendar.png`：黄色日程助手，橙色围巾。

四张独立图使用内置 image_gen 编辑工具，依据原图分别整理，不用代码描摹形象、不裁切整张海报来充当头像。均为 1254×1254 带 Alpha 的 PNG；原图保留，未覆盖。

共同提示要求：只保留指定角色，忠实保留阶梯体块、五官、颜色、配饰、材质和透视；完整居中，真正透明背景；去掉文字、其它角色、地面和大投影。没有更换角色设定。

编辑提示分别指定：珊瑚橙无配饰；紫色黑框眼镜；绿色深色耳机与灰色耳罩；黄色暖金体块与橙色围巾。

已知差异：提取图带轻微抗锯齿，部分有极低透明度边缘，留白和原海报略有差异。实际浅／深色界面仍须核对，不把生成成功当成视觉验收。当前不是严格整数网格的逐像素重绘，也没有生成静止／思考／招呼的整套动画。

素材目前用于独立设计稿。默认头像、自定义头像回退、应用图标、原生资源目录与最终体积优化将在实际产品接入 PR 中分别处理。
