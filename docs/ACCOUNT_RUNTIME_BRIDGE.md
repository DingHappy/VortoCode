# 同账号连接：运行端归属与短期读取授权

状态：本地源码、隔离跨服务及手机 Web OAuth 联调通过，未部署。云端助手目录和原生安全存储尚未接入。手机会话详见 [MOBILE_ACCOUNT_ACCESS.md](MOBILE_ACCOUNT_ACCESS.md)。

## 责任与完成范围

- 现有账号服务本地 `/api/me` 增加稳定 `user_id` 与 no-store，保留原 email/device 字段。本轮另为 OAuth 客户端绑定增加 devices/auth_codes.client_id 及兼容迁移定义；只在临时 SQLite 验证，未执行生产 DDL，现网版本未验证或部署。
- `src/gateway/account_service.py` 向运行端固定的账号 origin 核验访问令牌，取得稳定账号和设备身份。签发源必须与调用方登录来源一致，不能随配置变化把旧凭证转发给另一服务。请求不跟随重定向、不带 Cookie、不借环境代理，5 秒超时，JSON 响应有 16KB 上限。
- `src/gateway/account_registration.py` 将此助手绑定到已核验的账号。持久实例 ID、账号归属及 revision 与原设备授权共用一个私有原子文件和跨进程锁，不新增任务或身份数据库。
- 同账号的另一设备可以获得仅用于该实例的短期只读凭证；不同账号、不同签发源、过时 revision 和被撤销设备会被拒绝。邮箱仅作显示，不参与归属。

## 内部接口

以下接口必须有原 Gateway 管理员身份，仅供可信原生端或服务端 OAuth 回调桥使用。它们不是公开的手机账号令牌转发接口，不应让用户复制账号凭证，也不能把 Gateway 管理员令牌发给手机。

| 接口 | 输入/效果 |
| --- | --- |
| `GET /api/mobile/account/registration` | 读取本运行端实例、登记和 revision；不访问账号服务，不写文件 |
| `PUT /api/mobile/account/registration` | issuer、access_token、name、revision；实时核验账号后登记，初始 revision 为 0；已有不同归属必须先明确解绑 |
| `DELETE /api/mobile/account/registration` | revision；解绑并撤销原账号读取授权，无需云端可用；保留递增版本防止旧请求作用于新归属 |
| `POST /api/mobile/account/connect` | issuer、access_token、registration_revision、request_id、device_token、previous_expires_at、name；核验同账号后发放/续期本实例短期只读授权 |

外层管理员身份与内层账号证明都必须有效。手机自报 user_id/owner 等额外字段会被拒绝。未核验账号不能先到先得认领助手，单独持有账号令牌也不能调用这些内部接口。

资源请求继续使用原 `/api/mobile/v1/bootstrap` 和 `/snapshot`；资源凭证不能访问其它管理员或执行接口。账号服务的访问/刷新令牌不返回给手机资源读取器，也不写入运行端授权文件。

## 授权期限与重试

读取租约有效期为 300 秒。每次发放/续期都重新向账号服务核验；网络失败返回 503，明确账号拒绝返回 401，账号/设备不匹配返回 403，版本/来源或回执变化返回 409。来源不可用时不自动放行或续期。

可信客户端为一个设备连接生成稳定的 `request_id` 和随机资源凭证 `device_token`。初次 `previous_expires_at=0`，续期提交上一份回执的 expires_at。相同请求重试返回原回执，不重复延长、不新增设备；真正续期只更新同一条设备记录。代码模拟跨一天 300 次续期，仍只有一个设备记录；这不是 24 小时实机运行证明。

助手解绑、归属变更与运行端设备撤销立即使相应账号租约失效。账号服务退出/撤销会阻止下一次续期；**已经签发的租约最多继续有效 5 分钟**，不声称云端退出能即时撤销所有本地租约。原生退出流程仍需接入运行端撤销，才能取得更强的即时退出语义。

高级手动连接是管理员明确发放的另一种授权，其有效期/撤销规则保持原样。账号解绑不会静默改写这类授权；操作者可在设备管理中撤销它们。
