# Desktop 页面内容规范

2026-10-09，PRD第60节。以稳定日常使用为目标，优先回答「现在是什么状态」和「接下来做什么」。
本页是源码内容与交互规范，不代表完整截图视觉审查或原生验收。
界面结构、入口位置和视觉规范见 [Desktop 设计规范](DESIGN_SYSTEM.md)（2026-10-27 起为准）。

## 内容层级

1. 首屏显示主要动作、当前状态和需要用户处理的事项。
2. 模型、上下文、版本、构建和诊断说明按需展开，不挤占任务进展。
3. 没有内容的步骤/活动/队列不建立空区块；没有任何活动时只给一条下一步提示。
4. 出错、等待确认、未知覆盖、验收失效仍明确显示，不为了简洁隐藏风险或历史证据。
5. 不可用能力说明现状，不提供选了也不生效的控件；真实权限门不变。

## 用语与入口

| 位置 | 日常用语与处理 |
| --- | --- |
| 新建会话 | 新对话；与下派任务、后台工作分开 |
| 首页未配置模型 | 连接模型，进入模型设置；不要求本地模型用户先登录 |
| 账号页 | 云端账号可选，本地/第三方模型无需登录；原计费/登录逻辑不改 |
| 工作台 | 一个入口；运行时引向信息页，不新增重复按钮 |
| 运行信息 | 状态、步骤、活动和非空队列优先；会话详情默认折叠 |
| 技术用语 | 日常页面用本地引擎/会话/项目；诊断处保留准确的协议/标识 |
| 版本 | 顶栏简短版本；设置常规的版本与构建信息可展开 |
| 插件 | 管理工具连接与项目扩展；项目未选择时给选择项目入口 |

## 状态与真实性

当前主会话连接中断时给原连接设置入口；等待确认指向输入框上方原确认卡，不重复授权。
运行中没有活动不猜测具体工具阶段。已有失败活动继续显示，未知状态显示未知。
上下文百分比仍来自估算，窗口未知与历史预算分开，浮层不代表计费或压缩成功。
活动/计划的完成不推导任务验收、交接处理、持久交付或Goal达成；相应领域页面继续保留证据。
