## 内容层级

2026-11-01 修订：以[注意力优先的信息呈现](ATTENTION_DESIGN.md)为上位规则。主界面先交付结论、影响、建议和必要决定；步骤、活动、队列和诊断在用户展开后查看。下列历史迁移规则中涉及默认展开过程或常驻多块概览的内容，以此项为准。重要失败、来源失联和不确定结果仍需明确提示。

1. 首屏显示主要动作、当前状态和需要用户处理的事项。
2. 模型、上下文、版本、构建和诊断说明按需展开，不挤占任务进展。
3. 没有内容的步骤/活动/队列不建立空区块；没有任何活动时只给一条下一步提示。
4. 出错、等待确认、未知覆盖、验收失效仍明确显示，不为了简洁隐藏风险或历史证据。
5. 不可用能力说明现状，不提供选了也不生效的控件；真实权限门不变。

## 状态与真实性

当前主会话连接中断时给原连接设置入口；等待确认指向输入框上方原确认卡，不重复授权。
运行中没有活动不猜测具体工具阶段。已有失败活动继续显示，未知状态显示未知。
上下文百分比仍来自估算，窗口未知与历史预算分开，浮层不代表计费或压缩成功。
活动/计划的完成不推导任务验收、交接处理、持久交付或Goal达成；相应领域页面继续保留证据。

## 过程与输出（第66节）

工具/阶段记录执行时展开，同一回合非空最终回复后缩略，可再次查看。
失败、等待处理、超时、取消、无输出停止不自动收起；人工收起仍有异常摘要。

2026-11-03 工具回执修订：对话完成、失败或取消只结束本轮阶段；未收到自身结束回执的工具和 Hook 显示「状态待核对」，保留原名称与参数，后续明确回执仍可按原 id 更新。时间线逐行显示完成、失败、调用受阻、取消和超时（受阻可能已发生部分动作，是否执行以具体回执为准），展开后分开查看调用参数、返回结果和错误信息。空字符串回执明确标为空；没有回执不补造结果。用户手动展开或收起后，本组件实例保留该选择，异常数量始终留在标题。界面沿用现有聊天时间线、设计变量和原事件流，无新增执行入口或授权动作。

本轮浏览器验收入口为 `desktop/qa/timeline.html`：合成回执通过生产事件映射与组件展示，可检查失败、取消、缺失及迟到回执、深浅主题、窄区域和折叠状态。组件验证不代表真实模型表现或已安装原生应用验收。
