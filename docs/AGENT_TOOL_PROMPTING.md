# 主提示与授权结果

本切片只改变主 Agent 的静态指引、当前目标与授权反馈，不包含记忆导出或新增工具类型声明。

主提示按实际装配的工具组合指引。先行动、检查结果、再报告；历史请求和压缩纪要保留历史属性，不能恢复已取消的目标。角色文件只定义表达与协作偏好，不授予权限。现有成员返工上下文由 main 的 team_members 提供，不再另加一份。

原生调用沿用请求里的结构化 schema，系统目录不重复完整 JSON；提示式目录从 Tool 导出同一合同。串行、外向和不可信来源标记明确展示。日期、计划和结果仍放在消息流；静态前缀不随进度变化。恢复指纹包括有效工具合同、有效指引、两档模式与结果格式版本。

EscalationDecision 区分已授权、未获授权、缺少通道、超时、异常和过期结果。并发请求共用本回合决定，回合重置使迟到决定失效，取消向上传播。该决定仅管理 plan 升级，不能代替工具确认门、能力档案、deny 或沙箱。

小组指引遵守现有角色、执行框架与并发限制；不包含已删除的累计额度和 team_add_budget。学习 Claude Code 的部分是按能力组合指引、依赖串行、局部上下文与执行证据区分，不复制完整厂商提示词，也不代表模型训练或质量评测。

验证使用脚本模型和合成资料，覆盖实际请求、历史裁剪、授权异常、并发、重置与迟到决定。真实模型的完成率、成本和安装端体验仍需单独验证。
