主人决定，2026-11-14：整体学习 agentes.chat 的界面和操作形式，保持 VortoOne
现有许可，独立实现。不迁入其组件、样式、图标、品牌素材或后端。

完整安装、引导、页面逻辑与选定角色家族见 [个人体验设计](design/personal-experience/README.md)。
其中 15 个可点击页面是目标设计与合成演示；#882 基础已合入，后续生产接入分批推进。

## 范围与原有合同

继续个人模式：每个运行端一个个人空间，里面管理多个明确登记的项目。
Desktop 先完成完整流程，手机使用共同变量，并按原生交互单独适配。
公司多人互联继续保留为后续方向，不在本次自动开启。

原会话、任务、岗位、审批、调度、记忆和制品仍是权威来源，不增加第二套记录或连接状态。
切空间继续核对原连接代次，未发送内容留在原会话；旧项目归属未知继续保留未知。
主人确认、污点、岗位校验、禁用动作、审批轮次/实例、无人值守默认拒绝保持原规则。

## 顺序与验收

| 批次 | 页面和行为 | 验收要求 |
| --- | --- | --- |
| F1 | 共同设置组件、安装引导、设置分组与保存位置 | 本机和远端合成流程可走通；失败可返回；未确认不安装；旧目标失效可见。 |
| F2 | 空间、侧栏与主界面 | 日常入口清晰；同名空间可辨认；切换不串草稿、回包或审批。 |
| F3 | 消息、输入、执行过程和结果 | 状态、失败和下一步可见；技术详情按需展开；流式更新不抢焦点。 |
| F4 | 专员、小组、例行工作、资料库与连接 | 每个现有操作有明确入口、状态和结果，使用原授权和领域服务。 |
| F5 | 手机与完整验收 | 共同变量生成物一致；按真实中文、窄窗口、深色、空数据、长列表和失败核对。 |

按可审查范围分 PR。第一批落共同组件、F1/F2 的 Desktop 基础，以及 F3 的单工具摘要；
F4 先接通原页面入口，页面内部的完整改版与 F5 手机布局仍待后续。未完成就保留未完成，不把组件夹具、合成回执或截图当作已安装产品的
真实使用验收。合并、发布和部署需要主人另行授权。

## 呈现规则

- 共用分组、设置行、字段、状态与详情，不在每页重新定义同类控件。
- 正文先说明当前任务或结果。用途说明可展开；错误、目标失效、操作后果和等待确认
  保持可见。原确认仍展示作决定所需的信息。
- 安装先选位置，再准备缺项。模型配置已保存只说明保存，不代表推理或工具已验证。
  安装、启动、连接仍各自明确操作，复制模型配置仍需主人同意。
- 设置按个人、助理与更多选项分组。搜索覆盖全部设置，直接定位可以展开对应分组；
  切分类保留原草稿。诊断身份放连接详情，当前空间与各项保存位置保持可见。
- 颜色、字号、圆角、间距与尺寸来自 `design/tokens.json`。按钮使用明确动词；
  不把执行结束写成验收通过，不把已发送写成已完成。
- 侧栏区分日常入口与会话：工作动态、定时、专员和资料库便于直接进入；低频项收进更多。
  日常页复用原组件与记录，对话右侧仍可回查相同资料，不恢复已退役编码工作台。
