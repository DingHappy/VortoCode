# VortoOne 前端改版

主人决定，2026-11-14：所有界面统一学习 agentes.chat 的界面和操作形式；专员不再设独立的展示页，按统一角色入口呈现。保持 VortoOne
现有许可，独立实现。不迁入其组件、样式、图标、品牌素材或后端。

## 范围与原有合同

继续个人模式：每个运行端一个个人空间，里面管理多个明确登记的项目。
Desktop 先完成完整流程，手机使用共同变量，并按原生交互单独适配。
公司多人互联继续保留为后续方向，不在本次自动开启。

原会话、任务、岗位、审批、调度、记忆和制品仍是权威来源，不增加第二套记录或连接状态。
切空间继续核对原连接代次，未发送内容留在原会话；旧项目归属未知继续保留未知。
主人确认、污点、岗位校验、禁用动作、审批轮次/实例、无人值守默认拒绝保持原规则。

## 顺序与验收

| 批次 | 页面和行为 | 验收要求 |
| --- | --- | --- |
| F1 | 共同设置组件、安装引导、设置分组与保存位置 | 本机和远端合成流程可走通；失败可返回；未确认不安装；旧目标失效可见。 |
| F2 | 空间、侧栏与主界面 | 日常入口清晰；同名空间可辨认；切换不串草稿、回包或审批。 |
| F3 | 消息、输入、执行过程和结果 | 状态、失败和下一步可见；技术详情按需展开；流式更新不抢焦点。 |
| F4 | 角色、小组、例行工作、资料库与连接 | 每个现有操作有明确入口、状态和结果，使用原授权和领域服务。 |
| F5 | 手机与完整验收 | 共同变量生成物一致；按真实中文、窄窗口、深色、空数据、长列表和失败核对。 |

按可审查范围分 PR。第一批落共同组件、F1/F2 的 Desktop 基础，以及 F3 的单工具摘要；
F4 先接通原页面入口，页面内部的完整改版与 F5 手机布局仍待后续。未完成就保留未完成，不把组件夹具、合成回执或截图当作已安装产品的
真实使用验收。合并、发布和部署需要主人另行授权。

## 呈现规则

- 共用分组、设置行、字段、状态与详情，不在每页重新定义同类控件。
- 正文先说明当前任务或结果。用途说明可展开；错误、目标失效、操作后果和等待确认
  保持可见。原确认仍展示作决定所需的信息。
- 安装先选位置，再准备缺项。模型配置已保存只说明保存，不代表推理或工具已验证。
  安装、启动、连接仍各自明确操作，复制模型配置仍需主人同意。
- 设置在主区打开，按账号、个人空间、模型与执行、连接与工具、高级与关于分组；组内用横向分类。搜索覆盖全部设置，直接定位可以展开对应分组；
  切分类保留原草稿。诊断身份放连接详情，当前空间与各项保存位置保持可见。
- 颜色、字号、圆角、间距与尺寸来自 `design/tokens.json`。按钮使用明确动词；
  不把执行结束写成验收通过，不把已发送写成已完成。
- 侧栏区分日常入口与会话：主要聊天、工作动态、定时工作、资料库和更多；下面按频道、角色、小组与旁聊分组。角色直接显示实际登记名录，不另设专员主导航或形象展台。
  日常页复用原组件与记录，对话右侧仍可回查相同资料，不恢复已退役编码工作台。

## 统一角色与全界面参考（2026-11-14 补充）

所有新改页面都沿用同一视觉和操作依据，不为某个领域另起一套产品样式。
当前参考的落点如下；“入口已接通”不等于内部全部重做。

| 路径 | 共同形式 | 现有实现与边界 |
| --- | --- | --- |
| 安装、引导、运行位置 | 先选择在这台 Mac 运行或连接已有电脑，再逐步处理缺项、模型与确认 | 保留原 RuntimeOnboarding / LocalResident 的显式安装、复制配置与失败返回，不因改版自动安装或启用调度。 |
| 个人空间、聊天、频道 | 全局搜索栏、空间侧栏、圆角主区；频道和角色分组；消息身份清楚 | 复用原空间、SID、输入草稿与频道操作；不增加第二套 workspace 或聊天库。 |
| 角色资料 | 侧栏实际角色列表；总助手和登记角色用同一个资料弹层；设置、工具与权限、记忆或工作记录用标签切换 | 总助手读取原资料和记忆；登记角色读取原 StaffSnapshot。角色没有独立私聊服务时，仍由总助手安排任务，不伪造私聊或自动派活。 |
| 添加角色 | 简短表单说明名字与分工，核对已有权限方案 | 当前准备可编辑的对话草稿，保留原输入；不自动发送、登记或授予权限。之后仍使用原提议与主人批准。 |
| 全局设置 | 主区内的紧凑分组导航、横向分类、分组表单与按需详情 | 所有既有设置页可达，保存位置和目标失效明确展示；搜索、切分类保留草稿，离开需先处理未保存修改。 |
| 动态、任务小组、定时工作、资料库、连接与技能 | 沿用共同主区、标题、状态、分组行与详情规则 | 原领域页和操作入口继续可用；内部复杂表单按 F4 逐页迁移，不用截图代替任务执行或审批验收。 |
| iPhone | 共享角色用词、颜色和尺寸变量，按原生导航适配 | 本步只同步共同生成物，不声称 iPhone 各页面已重构或真机验证。 |

已选定的四个角色形象用于默认身份，已有自定义头像优先。形象不代表角色已经登记、启用或获准。
当前弹层固定打开时的资料快照；连接或个人空间变化后，旧内容仅供回查且禁止动作，需重新打开。
添加角色时的权限方案也固定在原目标，避免旧窗口展示另一个空间的新方案。

实际应用截图可能包含个人资料，仅供本机核对，不上传仓库或 PR；提交的验收图全部来自真实组件和合成数据。
