# Desktop 设计规范

2026-10-27 定，2026-11-01 按用户确认的注意力优先方向修订，2026-11-05 按 ADR-016 改为以会话为中心（第 1～4、8 节）。往后 Desktop 的界面改动以本文及[信息呈现与打扰规则](ATTENTION_DESIGN.md)为准。这是目标形态，现有界面按第 8 节分批迁移，没迁移到的部分照旧可用。用词与文案沿用 [Desktop 页面内容规范](DESKTOP_CONTENT_GUIDELINES.md)。

## 1. 原则

1. **先替用户处理信息**。默认呈现结论、影响、建议和必要决定；模型、Bot 分工、进度日志与配置按需展开。普通问答直接回答，需要持续跟进才形成工作事项。
2. **以会话为中心**。侧栏只放会话（主要聊天、任务小组、旁聊）；主区居中、单栏；右侧面板由用户主动打开，收起后不留占位——主要聊天的右侧是助理面板（头像名片 + 五个标签，仿 Muse，保持不变），任务小组的右侧是小组详情。要用户处理的事只在主要聊天顶部集中出现一次，其它位置只放角标，不再各自列一份。
3. **后台工作安静推进**。正常进度不反复打扰，待处理、失败、来源失联和结果不明保持显式提示。动态先给重点摘要，完整过程与历史由用户展开；后台更新不抢走当前视图和输入。
4. **风险越高越显眼**。只读的动作不打扰用户；会改东西的，在对话里内嵌确认卡；收不回的，标红并写明后果。
5. **特色来自取舍，不来自装饰**。不用渐变、大色块或多种强调色。颜色只表达状态，衬线字只用在首页问候这一处。例外只有助理面板里的头像，以及「身份」标签里 SOUL、记忆两张卡，它们代表助理本身，可以用渐变。

## 2. 功能放哪：三层

| 层 | 放什么 | 判断标准 |
| --- | --- | --- |
| 侧栏：会话 | 新对话、搜索（⌘K）；**主要聊天**（置顶，角标 = 等你的件数）、**任务小组**（每个小组一条，带状态词）、**旁聊**（默认显示最近 5 条）；底部是常驻电脑状态和「设置」 | 是一段可以对话的东西。侧栏不放功能入口，也不加全局模式 |
| 右侧面板 | 主要聊天：**助理面板**（头像名片 + 动态、目标、审核记录、定时、身份五个标签，规格见第 4 节，保持不变）。任务小组：**小组详情**（成员、验收标准与证据、用量、交付分支） | 助理自己的事进助理面板已有的标签；和某个小组有关的进小组详情 |
| 设置 | 资料库、插件与连接、模型、账号与会员、手机与设备、更新与诊断 | 设一次就很少再动，或者偶尔回查 |

另外有两个固定位置：

- **主要聊天顶部「等你处理」**：唯一汇总要用户处理的事的地方，规格见第 4 节。
- **输入框的「+」菜单**：附件、这次要用的插件、派活、交给 Codex、设成目标、定时重复——只在某一句话里用一下的。
  「此对话的能力」是同一入口下的只读回查窗口：按需查看当前运行端为当前会话装配的工具和连接，
  不添加侧栏入口、顶栏状态条或权限开关。工具声明、连接观察、账号核实和动作授权分别写清楚；
  旧端/断线/不完整清单保持未知，不能用「已装配」暗示「已授权」。窗口沿用字号、色彩和焦点规则。
  需要核对的内联连接信息展开后，刷新恢复正常仍保持展开，直到用户主动收起。

### 新功能怎么定位置

依次问三个问题：

1. 它是一段可以对话、会持续产生消息的东西吗（比如一个新的小组、一个外部 Agent 会话）？是，就作为一条会话进侧栏。
2. 它是助理自己的事（它在做什么、记住了什么、允许过什么、什么时候做）吗？是，就放进助理面板已有的标签；和某个小组有关的，放进小组详情。助理面板不加第六个标签。
3. 其它的放设置；只在某一句话里用一下的，放「+」菜单。

需要用户处理的事，一律进「等你处理」，并以确认卡出现在对应会话里；**不得**另做角标列表、顶栏胶囊或单独的待办页。

## 3. 页面模板

| 页面 | 结构 |
| --- | --- |
| 主要聊天的空状态 | 打开 App 直接进主要聊天；还没有消息时，居中一句问候（衬线 34）+ 大输入框 + 3～4 个建议 chip |
| 对话 | 顶栏（会话名，小组另加状态词）+ 单栏对话（最宽 736，居中）+ 底部输入框；主要聊天在对话上方放「等你处理」 |
| 任务小组 | 顶栏：简短的小组名 + 状态词；对话是群聊；底部输入框旁放「退回」「验收通过」（交付后才出现，主按钮尺寸）；详情面板见第 4 节 |
| 列表页（资料库） | 页面标题 + 分组列表；选中一项后，在右侧或下方显示详情 |
| 任务详情（点「动态」里的一条打开） | 标题和来源，右上角放「打开电脑看 / 暂停 / 停止」；正文是步骤账本；底部放「给这件任务补一句」 |
| 设置 › 插件与连接 | 标签（插件 / 连接 / 技能）+ 卡片网格；选中一张卡，右侧显示详情和按动作分级的权限 |

## 4. 交互模式

**等你处理**（主要聊天顶部）
- 有事要用户处理时出现一行紧凑的「等你处理 · N」，默认收起；文字为中性色，只有数量用小面积琥珀色标记。没有事项且来源完整时不占位置。
- 用户主动展开，切换小组或旁聊再回来保持本次连接内的选择；换运行实例、工作区或连接代次后默认收起。后台新记录不擅自展开、抢焦点或移动输入。
- 每件事一行：一句话说明（谁、要什么）+ 一行说明（后果或依据、时间）+ 右侧的动作按钮，和对话里的确认卡用同一套按钮与顺序。
- 收录：小组交付与提问、Codex 动作、审批、到点提醒。失败、中断和来源失联提供独立的「N 项需核对」入口，宽度不足才换行，不和等你的混在一起。
- 动态面板保留异常、最近结果与完整历史，以一行链接返回主要聊天处理待办，不再列第二份待办摘要。侧栏、顶栏辅助入口与该链接使用和主汇总相同的数量口径，来源不全保留「+」。
- 侧栏「主要聊天」的角标只计「等你」的件数。不再有顶栏任务胶囊。

**内嵌确认卡**（对话中）
- 先由助理用一句话说明要做什么。
- 卡片依次写清楚：动作和对象（比如「发给 Codex · 查看当前改动」）、具体内容、后果（比如「发出后不能撤回」）。
- 按钮顺序是「修改 · 不发 · 发送」，主按钮放在最右边。
- 字号、圆角和对话保持一致，不另起一套样式。

**风险分级**

| 级别 | 例子 | 表现 |
| --- | --- | --- |
| 读取 | 查日程、读邮件 | 默认直接允许，不弹确认 |
| 改动 | 存草稿、新建日程、给 Codex 发话 | 内嵌确认卡，默认「每次问我」 |
| 收不回 | 发送、付款、删除 | 红色标注后果。目前一律不支持，或者每次都要确认，不能设成「直接允许」 |

插件和连接的权限，按动作逐项设置：直接允许 / 每次问我 / 不允许。目前每个动作的级别由插件自己定，详情里只照实写出「只读 / 每次问你 / 不支持」，不放改不了的开关；能逐项设置后再换成选择框。

**步骤账本**（任务详情）
- 后台任务先显示一句标题、当前结果状态与可做的动作；完整要求、旧消息与日志按需展开。小组内部任务标明所属小组、执行成员与协调人审阅职责，提供返回小组入口。
- 小组有交付时先展示「交付与原文」，保留可切换的「小组经过」。总结、验收证据和成员交回文本各自可展开；不把总结冒充全文，也不根据最新时间猜测最终版本。已保存文本可能受长度限制，缺失时如实提示补交。
- 可读结果使用现有安全 Markdown 子集，HTML 与脚本转义，不加载图片或自动访问链接；原始群聊消息继续按纯文本呈现。复制只复制当前已读取文本，不触发批准、验收、模型调用或重试。
- 每一步一行，状态符号依次是：○ 未开始、◐ 进行中、✓ 完成、✕ 失败。
- 正在进行的那一步展开，显示命令和进度；其余步骤折叠成一行，右侧写耗时。
- 工具调用和思考过程默认折叠。

**助理面板**（主要聊天右侧，仿 Muse，保持不变）
- 宽 352。窗口窄于 1100 时盖在对话上面，不挤占对话宽度。右上角有关闭按钮，收起后对话居中、不留占位，开关状态要记住。
- 上半部分使用紧凑身份行：头像 32、名字和当前连接位置；资料编辑可达。模型与「打开电脑看」收在默认折叠的「运行信息与电脑」。连接失败说明及「重新连接」保持可见，不让身份展示挤占工作内容。
- 名片下面是标签条：动态、目标、审核记录、定时、身份。只显示图标，悬停出名字，标签之间用细竖线隔开，选中的那个是白底胶囊。有事等你时，「动态」图标上亮一个琥珀色圆点。
- 每个标签页开头一个粗标题（15、600），下面是面板列表行：图标（34，圆形或圆角方块）+ 标题 + 一行说明 + 时间，右侧放状态词或展开箭头，行间不加分隔线。只有等你（琥珀）和在忙（蓝）的图标带颜色，其余用填充色底。
  - 动态：默认按「等你处理 / 需要核对 / 最近结果」显示。最近结果最多三条，待处理与异常不截断。例行巡视（如 Codex 半小时进度）折叠成一行「例行巡视 N 条」，有变化的那条单独显示。普通回执、对话与历史进度收在「查看全部记录」，展开后按时间查看；摘要保留原状态与证据，不推断验收。
  - 目标：每条下面一条细进度条，写下一步和期限；点开在弹窗里编辑，面板里不直接摆编辑表单。今日概览放在这页底部。
  - 审核记录：每条写想做什么、为什么，下面写「已允许 / 始终允许 / 没允许 · 日期」，点开看原文；同一类请求连续出现时合并成一条并标次数。
  - 定时：按每日、每周分组，右侧写下次时间或今天的结果。
  - 身份：一张名片卡带「编辑」，下面 SOUL、记忆两张卡并排，点了进各自的编辑页。
- 连不上常驻电脑时：头像变灰，状态变红，给「重新连接」；列表上方写明是几点读到的，不把旧数据当成现在。

**小组详情面板**（任务小组右侧）
- 宽 352，开合规则同助理面板。不做标签条，从上到下四个区块，每个区块一个粗标题（15、600）加右侧计数。
- 成员：角色、执行框架、在做 / 空闲、做了几轮。
- 验收标准：逐条带 ✓ 和证据的一句话摘要。
- 用量（只计数）、交付分支（有开发成员时）；最下面是文字按钮「停止小组」（红字）。

**按需面板**（详情、预览这类）
- 只在需要时打开，有明确的关闭按钮。
- 关闭后不留占位，和助理面板不同时出现。

## 5. 视觉

### 颜色（浅色）

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 底色 | `#FAFAF9` | 主区域 |
| 侧栏 | `#F3F3F1` | 侧栏 |
| 卡片 / 浮层 | `#FFFFFF` | 卡片、菜单、输入框 |
| 选中 | `#E7E7E4` | 侧栏当前项 |
| 浅填充 | `#F0F0EE` | 用户气泡、代码块、次级按钮底 |
| 分隔线 | `#E4E4E1`（描边）/ `#ECECE9`（分隔） | 卡片描边、列表分隔 |
| 正文 | `#18181B` | 正文、主按钮底 |
| 次要正文 | `#3F3F46` | 卡片正文 |
| 说明 | `#6B6B70` | 时间、来源、说明（在侧栏底色上对比度不低于 4.5:1） |
| 强调 / 进行中 | `#3355D1`（浅底 `#EEF1FC`） | 链接、进行中、已开启的开关 |
| 等你 | 文字 `#92400E` / 底 `#FEF3C7` / 点 `#D97706` | 等你处理 |
| 失败 / 收不回 | 文字 `#B91C1C` / 底 `#FDECEC` / 描边 `#F5D0D0` | 失败、卡住、危险操作 |
| 完成 | 文字 `#15803D` / 底 `#EAF5EE` | 已完成、在线 |
| 无法确认 | 文字 `#52525B` / 底 `#F0F0EE` | 结果无法确认 |

规则：

- 强调色只有蓝一种，主按钮用墨黑（`#18181B`）。
- 状态色只用来表达状态，不做装饰。
- 两种需要区分的状态，除了色相不同，明度也要不同。

深色模式按同样的角色映射，迁移时随变量文件一起补上。

### 字体与字号

- 界面用 Inter + Noto Sans SC（中文回落到 PingFang SC）。
- 衬线字（Noto Serif SC）只用于首页问候。
- 等宽字（JetBrains Mono）只用于命令、路径、编号。

| 字号 | 用途 |
| --- | --- |
| 34 衬线 | 首页问候 |
| 22 | 页面标题 |
| 18 | 区块标题、详情标题 |
| 15 | 对话正文、输入框 |
| 14 | 界面默认正文、菜单、按钮 |
| 13 | 次要正文、卡片说明 |
| 12 | 时间、来源、角标、分组标题 |

字重只用 400、500、600 三种。不使用 12 号以下的字，也不使用半号字。

回复中的大标题为区块级 18 号；表格按内容保留列宽，短英文名称不任意拆字，过宽时表格自身横向滚动。代码、引用、表格描边使用语义变量适配深浅主题。小组标题保持一行，完整目标可从标题提示和原有概览查看；成员按需展开。交付证据与小组正文同为 15 号、1.7 行高，清单项之间留 12px，避免正文之后突然变成密排小字。

### 间距、圆角、阴影、图标

- **间距**：按 4 的倍数，取 4、8、12、16、20、24、32、40。
- **圆角**：控件 8；嵌在控件里的小块（字标、分段切换的选中段）6；卡片和菜单 14；对话里用户的气泡 18；输入框 22；胶囊、标签、头像用全圆。
- **阴影**：两种，外加一层细影。
  - 输入框：`0 1px 2px rgba(24,24,27,.04), 0 8px 28px rgba(24,24,27,.07)`；
  - 浮层（菜单、弹出框）：`0 12px 32px rgba(24,24,27,.14)`。
  - 细影：`0 1px 2px rgba(24,24,27,.06)`，只用于分段切换的选中段。
  - 卡片不用阴影，只用 1px 描边。
- **图标**：统一用线性图标，描边 1.75。导航和按钮用 16px，步骤状态用 18px。
- **尺寸**：
  - 侧栏宽 248～264；
  - 对话栏最宽 736；
  - 助理面板宽 352，详情面板宽 320～380；
  - 页面左右内边距 28～40。

## 6. 组件

| 组件 | 规格 |
| --- | --- |
| 按钮 | 主要（墨黑底白字）、次要（透明底加描边）、文字（无底无框）、危险（红字红描边）。高 32，大按钮 34 |
| 侧栏项 | 高 34，左侧图标；当前项用选中底色加 500 字重；悬停只换浅底，不能和当前项混淆 |
| 分组标题 | 12 号说明色，不用大写或装饰 |
| 列表行 | 左侧状态符号，中间标题加一行说明，右侧放状态词或耗时；行间用分隔线。助理面板里的列表行见第 4 节，不加分隔线 |
| 卡片 | 白底、1px 描边、圆角 14；可选中的卡片，选中时用 2px 墨黑描边 |
| 胶囊 / 标签 | 全圆，12～13 号字，用状态色的浅底和深字 |
| 菜单 | 白底、圆角 14、浮层阴影；菜单项高 34～36；分组之间用细线隔开 |
| 开关 | 30×18；开启时用强调蓝 |
| 输入框 | 圆角 22、输入框阴影；左侧放「+」，右侧放模型选择和发送按钮；本次用到的插件以标签形式显示在输入框里 |
| 空状态 | 一句话说明现状，再给一个下一步动作。不出现空的区块 |

所有可点的东西都必须是真正的 `button` 或 `a`；只有图标的按钮要带 `aria-label`。

## 7. 状态词

不同界面里，同一种状态用同一个词：

| 状态 | 用词 | 颜色 |
| --- | --- | --- |
| 需要用户决定 | 等你 / 等你点头 | 琥珀 |
| 进行中 | 在忙 / 第 N/M 步 | 蓝 |
| 完成 | 办好了 / 已送达 | 绿 |
| 结果不明 | 无法确认 | 灰 |
| 失败 | 卡住了，需要你 / 失败 | 红 |

## 8. 迁移

- **新代码**：不写死字号、圆角和颜色，一律用变量（已有 `desktop/src/styles/tokens.css`）。
- **迁移顺序**（ADR-016）：
  1. 先修：打开小组时主要聊天同时显示选中；打开主要聊天不停在最新一条。
  2. 侧栏改成会话列表（资料库、定制收进头像菜单）；打开 App 直接进主要聊天；改掉输入框提示和输入框上方常驻电脑那行的过时说法。
  3. 主要聊天顶部的「等你处理」，同时去掉顶栏任务胶囊（先有新入口再拿掉旧的）；例行巡视折叠。
  4. 任务小组的右侧改成小组详情；助理面板内：动态里的例行巡视折叠、目标改为弹窗编辑、审核记录合并重复项；资料库、插件与连接移进设置。
  5. 对话里的工具名和编号收进「详情」；小组页面按第 3 节调整。
  6. iPhone 按同一结构跟进。
- **怎么迁移**：每批一个 PR，装好后截图对照。迁移不改变接口和数据。
- **旧样式**：被迁移覆盖后再删除，不提前大扫除。
