# Desktop 设计规范

2026-10-27 定。往后 Desktop 的界面改动都以本文为准。这是目标形态，现有界面按第 8 节分批迁移，没迁移到的部分照旧可用。用词与文案沿用 [Desktop 页面内容规范](DESKTOP_CONTENT_GUIDELINES.md)，本文只管结构、交互和视觉。

## 1. 原则

1. **一屏只做一件事**。首页负责开始，对话负责交代与回答，右侧的助理面板负责看它是谁、最近在做什么。不再为别的功能在对话旁边另开一列。
2. **对话是主角**。对话区居中、单栏。右侧只有助理面板这一个，可以收起，收起后对话居中、不留占位。
3. **后台工作和对话分开**。助理在后台做的事，用顶栏的任务胶囊和助理面板的「动态」呈现；对话里只出现需要用户决定的那一步。
4. **风险越高越显眼**。只读的动作不打扰用户；会改东西的，在对话里内嵌确认卡；收不回的，标红并写明后果。
5. **特色来自取舍，不来自装饰**。不用渐变、大色块或多种强调色。颜色只表达状态，衬线字只用在首页问候这一处。例外只有助理面板里的头像，以及「身份」标签里 SOUL、记忆两张卡，它们代表助理本身，可以用渐变。

## 2. 功能放哪：五层入口

| 层 | 放什么 | 判断标准 |
| --- | --- | --- |
| 侧栏顶部 | 「助理 / 工作台」模式切换 | 全局模式只有这一处 |
| 侧栏一级入口 | 新对话、搜索（⌘K），以及 3～5 个功能入口 | 会经常回来看。点了打开对应的整页，或者助理面板的对应标签 |
| 输入框的「+」菜单 | 附件、这次要用的插件、派活、交给 Codex、设成目标、定时重复 | 只在某一句话里用一下 |
| 头像菜单与设置 | 设备、设置、更新与诊断 | 设一次就很少再动 |
| 搜索与 ⌘K | 侧栏放不下的会话、页面和动作 | 兜底。侧栏是一份精选，不是功能清单 |

另外有两个固定位置：

- **顶栏右上角**：任务胶囊。
- **侧栏底部**：常驻电脑的状态，以及账号。
- **右侧助理面板**：头像名片和五个标签（动态、目标、审核记录、定时、身份），规格见第 4 节。

### 新功能怎么定位置

依次问四个问题：

1. 它是助理自己的事（它在做什么、记住了什么、允许过什么、什么时候做）吗？是，就放进助理面板已有的标签。
2. 它需要单独一页，而且用户每天都会回来看吗？是，就放侧栏一级入口。但侧栏一级入口加起来不能超过 5 个；超过时，先合并或降级已有的入口。
3. 它只在某一次对话里用一下吗？是，就放「+」菜单。
4. 它是设一次就不管的吗？是，就放设置，或者头像菜单。

右侧只保留助理面板这一个。新功能**不得**另开右侧面板，也不得给助理面板加第六个标签或新增第二个模式切换。

### 现有功能归位（助理模式）

| 功能 | 位置 |
| --- | --- |
| 主要聊天、旁聊 | 侧栏「最近」。主要聊天置顶并带星标 |
| 手机聊天、本机离线聊天 | 侧栏「最近」。在条目右侧标「手机」「本机」，不单独分组 |
| 动态、等你处理、派活、Codex 进度 | 助理面板「动态」标签；侧栏「任务」（带角标）和顶栏任务胶囊都打开它 |
| 定时（早晚报、签到、定时作业） | 助理面板「定时」标签；侧栏「定时」打开它 |
| 个人目标、今日概览 | 助理面板「目标」标签；侧栏「目标」打开它 |
| 制品、文件、早报存档 | 「资料库」页（侧栏一级） |
| 插件、连接的服务、个人技能 | 「定制」页（侧栏一级），分「插件 / 连接 / 技能」三个标签。整页做好之前，侧栏「定制」先打开面板的「身份」标签 |
| 名字、头像、关于你、性格（SOUL）、记忆 | 助理面板「身份」标签；头像右下角的笔直接改名字和头像 |
| 手机配对、设备 | 头像菜单 →「手机与设备」 |
| 审核记录 | 助理面板「审核记录」标签 |
| 模型、账号与会员、高级 | 设置（⌘,） |
| 更新、诊断日志 | 头像菜单 →「检查更新 · 诊断日志」 |
| 常驻电脑（状态、打开电脑） | 侧栏底部一行；助理面板头像下的「打开电脑看」 |

工作台模式沿用同一套侧栏骨架，一级入口换成工作台自己的功能，比如项目、变更、运行。具体清单在迁移工作台时补到这里。

## 3. 页面模板

| 页面 | 结构 |
| --- | --- |
| 首页（空状态） | 居中一句问候（衬线 34）+ 大输入框 + 3～4 个建议 chip；没有面板和标签 |
| 对话 | 顶栏（会话名 + 任务胶囊）+ 单栏对话（最宽 736，居中）+ 底部输入框 |
| 列表页（资料库） | 页面标题 + 分组列表；选中一项后，在右侧或下方显示详情 |
| 任务详情（点「动态」里的一条打开） | 标题和来源，右上角放「打开电脑看 / 暂停 / 停止」；正文是步骤账本；底部放「给这件任务补一句」 |
| 定制 | 标签（插件 / 连接 / 技能）+ 卡片网格；选中一张卡，右侧显示详情和按动作分级的权限 |

## 4. 交互模式

**任务胶囊**（顶栏右上）
- 平时显示「N 件在忙」，中性色。
- 有事要用户处理时，变成琥珀色「N 件等你 · M 件在忙」。
- 点击打开助理面板的「动态」标签。
- 侧栏「任务」的角标只计「等你」的件数。

**内嵌确认卡**（对话中）
- 先由助理用一句话说明要做什么。
- 卡片依次写清楚：动作和对象（比如「发给 Codex · 查看当前改动」）、具体内容、后果（比如「发出后不能撤回」）。
- 按钮顺序是「修改 · 不发 · 发送」，主按钮放在最右边。
- 字号、圆角和对话保持一致，不另起一套样式。

**风险分级**

| 级别 | 例子 | 表现 |
| --- | --- | --- |
| 读取 | 查日程、读邮件 | 默认直接允许，不弹确认 |
| 改动 | 存草稿、新建日程、给 Codex 发话 | 内嵌确认卡，默认「每次问我」 |
| 收不回 | 发送、付款、删除 | 红色标注后果。目前一律不支持，或者每次都要确认，不能设成「直接允许」 |

插件和连接的权限，按动作逐项设置：直接允许 / 每次问我 / 不允许。

**步骤账本**（任务详情）
- 每一步一行，状态符号依次是：○ 未开始、◐ 进行中、✓ 完成、✕ 失败。
- 正在进行的那一步展开，显示命令和进度；其余步骤折叠成一行，右侧写耗时。
- 工具调用和思考过程默认折叠。

**助理面板**（对话右侧）
- 宽 352。窗口窄于 1100 时盖在对话上面，不挤占对话宽度。右上角有关闭按钮，收起后对话居中、不留占位，开关状态要记住。
- 上半部分是名片：头像 120，右下角一个笔用来改资料；下面是名字（20）、一行状态（「● 已连接 · 住在常驻电脑」）、一行小字写模型，再下面是「打开电脑看」小按钮。不写「合上笔记本也照常干活」这类说明。
- 名片下面是标签条：动态、目标、审核记录、定时、身份。只显示图标，悬停出名字，标签之间用细竖线隔开，选中的那个是白底胶囊。有事等你时，「动态」图标上亮一个琥珀色圆点。
- 每个标签页开头一个粗标题（15、600），下面是面板列表行：图标（34，圆形或圆角方块）+ 标题 + 一行说明 + 时间，右侧放状态词或展开箭头，行间不加分隔线。只有等你（琥珀）和在忙（蓝）的图标带颜色，其余用填充色底。
  - 动态：「等你」一组排最上面，条目里直接放「去回答」；其余按今天、昨天分组。不放概览折叠行和筛选。
  - 目标：每条下面一条细进度条；今日概览放在这页底部。
  - 审核记录：每条写想做什么、为什么，下面写「已允许 / 始终允许 / 没允许 · 日期」，点开看原文。
  - 定时：按每日、每周分组，右侧写下次时间或今天的结果。
  - 身份：一张名片卡带「编辑」，下面 SOUL、记忆两张卡并排，点了进各自的编辑页。
- 连不上常驻电脑时：头像变灰，状态变红，给「重新连接」；列表上方写明是几点读到的，不把旧数据当成现在。

**按需面板**（详情、预览这类）
- 只在需要时打开，有明确的关闭按钮。
- 关闭后不留占位，和助理面板不同时出现。

## 5. 视觉

### 颜色（浅色）

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 底色 | `#FAFAF9` | 主区域 |
| 侧栏 | `#F3F3F1` | 侧栏 |
| 卡片 / 浮层 | `#FFFFFF` | 卡片、菜单、输入框 |
| 选中 | `#E7E7E4` | 侧栏当前项 |
| 浅填充 | `#F0F0EE` | 用户气泡、代码块、次级按钮底 |
| 分隔线 | `#E4E4E1`（描边）/ `#ECECE9`（分隔） | 卡片描边、列表分隔 |
| 正文 | `#18181B` | 正文、主按钮底 |
| 次要正文 | `#3F3F46` | 卡片正文 |
| 说明 | `#6B6B70` | 时间、来源、说明（在侧栏底色上对比度不低于 4.5:1） |
| 强调 / 进行中 | `#3355D1`（浅底 `#EEF1FC`） | 链接、进行中、已开启的开关 |
| 等你 | 文字 `#92400E` / 底 `#FEF3C7` / 点 `#D97706` | 等你处理、任务胶囊 |
| 失败 / 收不回 | 文字 `#B91C1C` / 底 `#FDECEC` / 描边 `#F5D0D0` | 失败、卡住、危险操作 |
| 完成 | 文字 `#15803D` / 底 `#EAF5EE` | 已完成、在线 |
| 无法确认 | 文字 `#52525B` / 底 `#F0F0EE` | 结果无法确认 |

规则：

- 强调色只有蓝一种，主按钮用墨黑（`#18181B`）。
- 状态色只用来表达状态，不做装饰。
- 两种需要区分的状态，除了色相不同，明度也要不同。

深色模式按同样的角色映射，迁移时随变量文件一起补上。

### 字体与字号

- 界面用 Inter + Noto Sans SC（中文回落到 PingFang SC）。
- 衬线字（Noto Serif SC）只用于首页问候。
- 等宽字（JetBrains Mono）只用于命令、路径、编号。

| 字号 | 用途 |
| --- | --- |
| 34 衬线 | 首页问候 |
| 22 | 页面标题 |
| 18 | 区块标题、详情标题 |
| 15 | 对话正文、输入框 |
| 14 | 界面默认正文、菜单、按钮 |
| 13 | 次要正文、卡片说明 |
| 12 | 时间、来源、角标、分组标题 |

字重只用 400、500、600 三种。不使用 12 号以下的字，也不使用半号字。

### 间距、圆角、阴影、图标

- **间距**：按 4 的倍数，取 4、8、12、16、20、24、32、40。
- **圆角**：控件 8；嵌在控件里的小块（字标、分段切换的选中段）6；卡片和菜单 14；对话里用户的气泡 18；输入框 22；胶囊、标签、头像用全圆。
- **阴影**：两种，外加一层细影。
  - 输入框：`0 1px 2px rgba(24,24,27,.04), 0 8px 28px rgba(24,24,27,.07)`；
  - 浮层（菜单、弹出框）：`0 12px 32px rgba(24,24,27,.14)`。
  - 细影：`0 1px 2px rgba(24,24,27,.06)`，只用于分段切换的选中段。
  - 卡片不用阴影，只用 1px 描边。
- **图标**：统一用线性图标，描边 1.75。导航和按钮用 16px，步骤状态用 18px。
- **尺寸**：
  - 侧栏宽 248～264；
  - 对话栏最宽 736；
  - 助理面板宽 352，详情面板宽 320～380；
  - 页面左右内边距 28～40。

## 6. 组件

| 组件 | 规格 |
| --- | --- |
| 按钮 | 主要（墨黑底白字）、次要（透明底加描边）、文字（无底无框）、危险（红字红描边）。高 32，大按钮 34 |
| 侧栏项 | 高 34，左侧图标；当前项用选中底色加 500 字重；悬停只换浅底，不能和当前项混淆 |
| 分组标题 | 12 号说明色，不用大写或装饰 |
| 列表行 | 左侧状态符号，中间标题加一行说明，右侧放状态词或耗时；行间用分隔线。助理面板里的列表行见第 4 节，不加分隔线 |
| 卡片 | 白底、1px 描边、圆角 14；可选中的卡片，选中时用 2px 墨黑描边 |
| 胶囊 / 标签 | 全圆，12～13 号字，用状态色的浅底和深字 |
| 菜单 | 白底、圆角 14、浮层阴影；菜单项高 34～36；分组之间用细线隔开 |
| 开关 | 30×18；开启时用强调蓝 |
| 输入框 | 圆角 22、输入框阴影；左侧放「+」，右侧放模型选择和发送按钮；本次用到的插件以标签形式显示在输入框里 |
| 空状态 | 一句话说明现状，再给一个下一步动作。不出现空的区块 |

所有可点的东西都必须是真正的 `button` 或 `a`；只有图标的按钮要带 `aria-label`。

## 7. 状态词

不同界面里，同一种状态用同一个词：

| 状态 | 用词 | 颜色 |
| --- | --- | --- |
| 需要用户决定 | 等你 / 等你点头 | 琥珀 |
| 进行中 | 在忙 / 第 N/M 步 | 蓝 |
| 完成 | 办好了 / 已送达 | 绿 |
| 结果不明 | 无法确认 | 灰 |
| 失败 | 卡住了，需要你 / 失败 | 红 |

## 8. 迁移

- **新代码**：不写死字号、圆角和颜色，一律用变量。变量文件随第一批迁移一起加入，之后会配一条检查，拦下新出现的写死值。
- **迁移顺序**：
  1. 变量文件和基础组件；
  2. 侧栏骨架和任务胶囊；
  3. 首页、对话和助理面板；
  4. 资料库、定制；
  5. 设置和头像菜单；
  6. 工作台。
- **怎么迁移**：每次迁一屏，截图对照后合并。迁移不改变接口和数据。
- **旧样式**：被迁移覆盖后再删除，不提前大扫除。
