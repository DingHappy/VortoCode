# 个人助理任务流程原型

这是独立的前端交互预览，用于评审「交代任务 → 执行位置 → 网站连接 → 登录接管 → 单次确认 → 结果」是否顺畅。沿用 `src/styles/tokens.css` 和现有 Lucide 图标，不接入生产 App、Gateway、模型或网站。

## 启动

使用已有 Desktop 开发环境，不需要新增依赖：

```bash
cd desktop
npm run dev -- --host 127.0.0.1 --port 15423 --strictPort
```

打开 `http://127.0.0.1:15423/qa/task-flow.html`。点击「从唐帕签到试试看」，再点击输入框的发送按钮。普通 `npm run build` 仍使用正式 App 入口，不会发布此预览。

## 演示范围

- 只演示一个唐帕任务；输入的文字作为任务说明，不执行任意指令。
- 顶部选择四种场景：未签到、已经签到、账号不符、结果不明。切换场景或重置会清空本次演示。
- 页面上的账号、日期、证据、提交次数和执行结果全部是合成数据。专用浏览器窗口由模态框代替，不打开真实网站，不收集密码、Cookie 或验证码。
- 全部状态仅在 React 内存中。刷新清空演示；重新开始会替换上一件示例任务，不代表完整历史、多任务或可靠持久化。
- 同一次演示内，正常结束后的再次检查会直接显示已签到；这只是界面状态演示，不是生产幂等保障。
- 常驻电脑的网站操作显示不可用；不通过界面开关冒充已获得远端能力。每日执行只展示尚缺条件，不启用调度。

## 评审步骤

| 场景 | 应观察到的行为 |
| --- | --- |
| 未签到 | 明确选择本机；建立连接；核对账号与站点日期后才能继续；只确认本次提交；结果依据显示 1 次模拟提交 |
| 已经签到 | 核对登录后直接结束；没有提交授权步骤；进度显示「无需提交」；模拟提交为 0 次 |
| 账号不符 | 无法勾选继续提交；返回暂停任务；演示切换账号后仍需重新勾选核对 |
| 结果不明 | 保留待核对；没有重试按钮；返回首页会继续当前任务；不可切换电脑或断开连接绕过；只读核对不清除待核对，人工核对后结束，提交仍为 1 次 |
| 提交前停止 | 中性停止状态；没有虚构已完成的进度；提交为 0 次 |
| 提交后停止 | 进入结果待核对，不声称提交已取消 |
| 完成后断开连接 | 保留这件任务已记录的执行电脑、账号与结果 |

另外检查：错误网站地址不能继续；连接名称不是网站账号；模态框 Tab 焦点循环、Escape 关闭；900/720/430 像素宽度无横向溢出；深浅主题状态色一致。

## 接入正式产品的后续边界

正式实现应复用现有会话、任务台账、连接作用域、确认门与浏览器待核对记录，由后端事件驱动显示。不得把本原型的内存状态、定时器、人工示例账号或提交计数当作真实执行证据。当前原型不证明真实登录续期、跨机接管、任务恢复、网站签到或无人值守执行已经可用。
