夹具复用生产侧栏、对话标题、输入框、助理面板、图标按钮和原生 dialog；仅合成内容，所有业务操作不接真实服务。

## 审查与调整

1. **已安装聊天界面与助理面板**：本轮现场截图显示身份入口使用指纹，侧栏/面板按钮缺少方向变化。
   这是识别成本问题；图标本身不会启用认证。新实现改为人物与方向明确的线性图标，沿用现有大小、色彩和布局。
2. **标签与键盘**：源码原来每个标签都在 Tab 顺序中，缺少方向键处理。新实现保持五个纯图标标签，
   单一 Tab 入口，方向键、Home/End 同步选择与焦点，正文有对应的 tabpanel 关系。
3. **提示与关闭层级**：读屏名称保留，可见提示支持焦点与悬停，固定定位避开视口边缘；
   原生 dialog 的提示进入原生顶层，Escape 优先收起提示，不误关弹窗。
4. **输入框快捷菜单**：「+」同样有可见提示。打开菜单后可直接 Escape 收起，焦点回输入框，未发送消息。

## 接续：菜单执行与面板焦点

本轮继续更新同一 PR #781。代码修复菜单焦点/高亮不一致时可能执行错误按钮的问题，
进入菜单先定位首项，Enter/空格交给当前原生按钮；关闭后先聚焦持久输入框再执行导航，
以便后续弹窗能回到正确入口。准备状态拦住 Enter，菜单外点击与移焦不抢回焦点。
菜单标题与说明、选项列表分开滚动。面板新增开关引用，键盘打开进入当前标签，
显式收起返回开关；表单内 Escape 不触发面板收起。

本轮 Chrome 合成界面已观察：

- 点击「+」焦点在添加附件；Shift+Tab 到关闭再 Enter：菜单收起、焦点回输入框、动作和发送计数仍为 0。
- Tab 到选择项目再 Enter：仅执行 project，次数增加 1；End/Home/方向键到模型后空格：仅执行 model。
- `/MODEL` 大小写匹配，输入框保留焦点，Enter 执行模型入口并清空命令。
- 已确认输入 `/no-such-command` 后 Enter：发送数维持 2；Escape 后 Enter 才增加到 3。
  较早一张 `05` 没有成功进入目标文本，不作为此项证据。
- 准备状态下保留「保留当前输入」，Enter 后发送计数仍为 3；恢复后可再次打开菜单。
- 打开菜单后点击外部弹窗入口，菜单收起；退出弹窗后焦点在原外部按钮，输入框草稿保留。
