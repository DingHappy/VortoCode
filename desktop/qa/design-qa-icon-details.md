# 图标与高频交互细节验收

独立分支 `codex/desktop-icon-interaction-polish`，基于 main `5160e4ec`；不包含 #776～#780。
入口 `/qa/icon-details.html`，运行 `npx vite --config qa/vite.config.ts --host 127.0.0.1 --port 5265 --strictPort`。
夹具复用生产侧栏、对话标题、输入框、助理面板、图标按钮和原生 dialog；仅合成内容，所有业务操作不接真实服务。

## 审查与调整

1. **已安装聊天界面与助理面板**：本轮现场截图显示身份入口使用指纹，侧栏/面板按钮缺少方向变化。
   这是识别成本问题；图标本身不会启用认证。新实现改为人物与方向明确的线性图标，沿用现有大小、色彩和布局。
2. **标签与键盘**：源码原来每个标签都在 Tab 顺序中，缺少方向键处理。新实现保持五个纯图标标签，
   单一 Tab 入口，方向键、Home/End 同步选择与焦点，正文有对应的 tabpanel 关系。
3. **提示与关闭层级**：读屏名称保留，可见提示支持焦点与悬停，固定定位避开视口边缘；
   原生 dialog 的提示进入原生顶层，Escape 优先收起提示，不误关弹窗。
4. **输入框快捷菜单**：「+」同样有可见提示。打开菜单后可直接 Escape 收起，焦点回输入框，未发送消息。

## 当前合成界面中已观察

- Right 从动态进入目标；End、Left、Home、Left 最终环绕到身份；计数 5 次、选中图形、焦点和正文对应。
- Escape 收起图标提示后保留当前标签；再 Tab 直接到当前正文，不经过另外四个标签。
- 点击「+」打开快捷菜单，Escape 关闭并回输入框。
- 原生弹窗里关闭图标的提示可见；第一次 Escape 只关提示，第二次关闭弹窗并回到原入口。
- 收起侧栏与面板后，保留「展开侧栏」「打开助理面板」入口，并显示对应方向的图形。
- 浅色 360px 合成面板中五个标签和提示可读，提示不受面板 overflow 裁切；深色右边缘提示也可见。
