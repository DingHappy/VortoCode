# 个人界面改版：第一批验收

## 参考与实现边界

参考主人提供的本机／远程选择截图、agentes.chat 官方界面图，以及源码
`a89b80b112dfef20958b7655f6d4165fc5e19884` 中的安装、侧栏、设置和工具摘要流程。
保留 Apache-2.0、VortoOne 品牌与现有图标库，独立编写组件、样式和文案。
没有迁入上游前端代码、CSS、字体或品牌资产。没有开启多人空间。

本批覆盖 Desktop 共同组件、首次设置、设置分组、空间选择、日常页入口和单工具摘要。
专员、例行工作、资料库等复用原组件与领域服务，页面内部的完整改版以及手机布局尚未完成。

## 浏览器实测

使用生产组件与合成 IPC／记录，不读写主人设置，不安装程序、不调用模型。
入口：`/qa/frontend-redesign.html`、`/qa/runtime-onboarding.html`、
`/qa/settings-redesign.html`；原版引导与新版均在 1280×900 截图核对。

| 检查 | 结果 |
| --- | --- |
| 运行位置选择 | 两张大卡片、中文标题、运行后果和可展开帮助均可见。 |
| 本机准备 | 未保存模型时先准备模型；保存只出现保存回执，不触发安装或启动。 |
| 安装同意 | 复制同意未勾选时安装禁用；勾选后才安装；默认不开启调度。 |
| 本机完整流程 | 分别安装、启动、连接后进入合成个人空间；每步有独立回执。 |
| 失败返回 | 合成安装失败显示错误和上次状态，可返回重新选位置。远程连接失败保留登记为待连接，不选中目标，不启动本机引擎。 |
| 日常页面 | 定时、目标、审核等在主区使用原组件；返回保留草稿，焦点回原入口；完整页面聚焦标题。 |
| 空间隔离 | A 输入后切 B 为空；B 输入后切回 A 恢复 A 草稿；没有合并或搬动数据。 |
| 资料库 | 选择资料、打开预览、选择历史版本、关闭预览均可操作；预览仍使用原沙箱。 |
| 设置搜索 | 搜索浏览器操作可展开更多设置并聚焦原控件；不改变操作权限。 |
| 设置草稿 | 编辑模型地址、切分类、切回仍保留输入；关闭弹出未保存提示。 |
| 浅色／深色 | 1280×900 的引导、聊天、设置与日常页文字和状态可读。 |
| 窄窗口 | 720×760 设置当前分类可见、无页面横向溢出；960×760 日常页面无多余空栏。 |

窄窗口检查发现更多分类曾被拉成整行，现已改为内容宽度，并在切分类或跨越布局断点时
把当前分类滚入可见范围。按钮保留键盘名称和原未保存提示。

工具摘要的行为测试覆盖单工具名称、持续运行回合、失败测试回执、未知状态和异常可见性。
来源失效提示保持在折叠详情之外。测试断言渲染与行为，不读取源码字符串。
